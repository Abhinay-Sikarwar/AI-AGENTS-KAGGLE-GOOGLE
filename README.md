# 🤖 AI Agents — Kaggle × Google AI (5-Day Intensive Learning Repository)

A structured, research-oriented repository documenting a 5-day intensive learning program on **AI Agents**, with hands-on exploration in:

- Agent architectures
- Tool calling & MCP
- Sessions, context & memory
- Agent quality & evaluation
- Prototype-to-production readiness

All work in this repository was completed using **Kaggle Notebooks**, with concepts aligned to the **Google AI / Gemini agent ecosystem**.

---

## 🎯 Purpose of this Repository

This repository serves as a **learning, experimentation, and research workspace** — capturing the complete journey of understanding AI Agents through:

- ✍️ Conceptual notes  
- 📓 Hands-on notebooks  
- 🎧 Podcast reflections  
- 📄 Whitepaper summaries  

The practical implementation of agent concepts was completed separately as a **mandatory capstone project**.

---

## 🧠 Learning Outcomes

By completing this repository, I developed:

- Understanding of **agentic system foundations & design patterns**
- Ability to construct **prompt → reasoning → action workflows**
- Familiarity with **Model Context Protocol (MCP) & tool-calling**
- Insights into **sessions, memory & context engineering**
- Awareness of **agent reliability, observability & evaluation**
- Readiness to extend agent systems toward **real-world production use**

This repository emphasizes **depth of understanding rather than codebase scale**.
