# 📘 Glossary

A quick-reference guide to important terms used throughout this project.  
This section helps readers, evaluators, and collaborators understand AI-agent-related concepts clearly.

---

## 🤖 AI Agent
An **AI Agent** is an autonomous or semi-autonomous system that:
- Observes its environment  
- Reasons about goals  
- Takes actions to achieve those goals  

> Example: An agent that analyzes a Kaggle dataset, decides which model to train, and evaluates results automatically.

---

## 🧠 Autonomous Agent
An agent that operates **without constant human input**, capable of planning, decision-making, and self-correction.

---

## 📚 LLM (Large Language Model)
A neural network trained on massive text datasets to understand and generate human-like language.

**Examples:**
- GPT family (OpenAI)
- Gemini (Google)
- LLaMA (Meta)

---

## 🔧 Tool Calling
A capability that allows an AI agent to:
- Call APIs  
- Run code  
- Query databases  
- Access external systems  

This enables agents to move beyond text generation into **real-world task execution**.

---

## ✍️ Prompt Engineering
The process of designing effective inputs (prompts) to guide LLM behavior.

Includes:
- Few-shot prompting  
- Chain-of-thought reasoning  
- Role-based prompts  

---

## 🧩 Multi-Agent System
A system composed of **multiple AI agents** that collaborate or divide tasks.

> Example: One agent for data preprocessing, another for modeling, and another for evaluation.

---

## 📊 Kaggle
A data science platform providing:
- Public datasets  
- Competitions  
- Cloud-based notebooks  
- Free GPU/TPU resources  

---

## 🌐 Google AI / Gemini
Google’s AI ecosystem and foundation models designed for:
- Reasoning  
- Multimodal tasks  
- Agent-based workflows  

---

## 🧪 Notebook Environment
An interactive coding interface (e.g., Kaggle Notebooks, Jupyter) combining:
- Code  
- Outputs  
- Documentation  

---

## 📈 Evaluation Metrics
Measures used to assess AI agent or model performance, such as:
- Accuracy  
- F1-score  
- BLEU  
- Human feedback  

---

## ⚠️ Hallucination
When an LLM generates **confident but incorrect or fabricated information**, a key challenge in agent reliability.
